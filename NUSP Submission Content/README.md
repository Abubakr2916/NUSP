# NUSP — Namal University Societies Platform

## Project Summary

NUSP is a proposed web platform for centralizing information about Namal University societies. Public visitors will be able to view society profiles, leadership information, upcoming events, announcements, and past-event galleries. Eligible Namal students will be able to apply for society membership or body positions, subject to the project's eligibility rules. Event registration is outside the project scope, and each student may enroll in only one society.

## Proposed Technology Stack

* **Frontend:** React or Next.js (to be finalized after consultation with university IT)
* **Backend:** Node.js or Python with FastAPI (to be finalized after consultation with university IT)
* **Database:** To be confirmed after consultation with university IT
* **UI/UX Design:** Figma
* **Version Control and Collaboration:** Git and GitHub
