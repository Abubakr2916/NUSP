# NUSP
Namal University Societies Platform - Software Engineering Project

## Project Overview

NUSP is a web-based platform proposed to centralize information and management for Namal University societies. It will provide public access to society profiles, leadership information, upcoming events, galleries, and announcements.

Verified Namal students will be able to apply for society bodies according to defined eligibility rules. Society Patrons and the Chief Patron will have management dashboards with permissions appropriate to their roles.

## Main Features

* Public landing page and society profiles
* Upcoming events and past-event galleries
* Society leadership information
* University-student authentication
* Applications for General Body, Executive Body, and Core Body
* One-society membership restriction
* Society Patron and Chief Patron dashboards
* Announcements and society information management

## Proposed Technology Stack

* Frontend: HTML, CSS, JavaScript, React
* Backend: Node.js and Express.js
* Database: MySQL
* UI/UX Design: Figma
* Version Control: Git and GitHub
